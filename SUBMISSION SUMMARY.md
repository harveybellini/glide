## 2. Submission Requirements & Form Fields

The **Additional Info** section includes mandatory (`*`) and optional fields required for submission. *Note: Information in this section is intended for judges and organizers and will not appear on the public project page unless specified.*

### Submitter Profile
* **Submitter Type (`*` Required):**
  * Individual
  * Team of Individuals
  * Organization
* **Country of Residence (`*` Required):** Selected from standard ISO country list.
* **Organization Name:** Required if submitting on behalf of an organization.

### Category / Track Selection
* **Track (`*` Required - Appears in Project Gallery):**
  * `Everyday Agents`
  * `Professional Agents`
  * `Good Neighbor Agents`

### Technical Assets & Repository
* **Public Code Repository URL (`*` Required):**
  * Must include all source code, assets, and setup instructions.
  * Must feature an **MIT or Apache open-source license** clearly visible in the repo's *About* section and `README`.
* **Architecture Diagram (`*` Required):**
  * Accepted formats: `PDF`, `PPT`, `PPTX`, `PNG`, `JPG`, `JPEG`
  * Maximum size: 35 MB
* **AWS Builder ID:** Required for identifier/verification.

### Optional Submissions & Demos
* **Live Demo URL:** Optional, but noted that projects with a live demo score higher on *Technical Implementation*.
* **Testing Instructions:** Optional instructions to assist judges with running/evaluating the app.
* **Bonus Blog Post URL:**
  * Must be published on `builder.aws`.
  * Title must include the phrase **"Agents for Humans"**.
