## 📝 Required Fields & Guidelines

### 1. Project Story (`* Required`)
Write your detailed project overview using **Markdown** formatting (with LaTeX support for math equations).

* **Recommended Content Sections:**
  * **Inspiration:** What problem are you solving and why?
  * **What it does:** Explanation of the agent's core function and workflow.
  * **How we built it:** Integration of Strands Agents SDK, AWS services, Bedrock AgentCore, architecture overview.
  * **Challenges faced:** Technical roadblocks or obstacles overcome during development.
  * **What we learned:** Key takeaways and experience gained.
  * **What's next for the project:** Future roadmap and improvements.

* **Formatting Quick Reference:**
  * `## Headline` for section titles
  * `**bold**` / `_italics_`
  * `[Link Title](URL)` for external links
  * `![Alt text](image_url)` for embedded images
  * ` ```python ... ``` ` for code blocks
  * `\( ... \)` (inline math) or `$$...$$` (block math) for LaTeX equations
